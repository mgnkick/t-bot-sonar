# t-bot-sonar

Telegram-бот с командами `/start`, `/go`, `/buzz` и `/help`. Он дважды в день публикует в `CHANNEL_ID` рейтинговую подборку из трёх популярных материалов о компьютерных сетях и интернете: в 08:00 и 18:00 по UTC+3. В выпуск входят короткие описания из RSS или публичного HN API, рейтинг/обсуждение, ссылка на первоисточник и ссылка на сайт из `SITE_URL`. Повторные материалы отсеиваются в течение двух дней.

Источники популярности: Hacker News Top/Best и публичные RSS Lobsters (главная, networking и security). Для публикаций Telegram бот должен быть администратором канала с правом публикации сообщений. Установщик использует long polling, поэтому входящий порт на сервере открывать не нужно.

## Запуск на Ubuntu через systemd

1. Создайте бота у `@BotFather` через `/newbot` и получите токен.
2. Создайте `/etc/t-bot-sonar.env` с переменными `BOT_TOKEN=...`, `SITE_URL=https://179.253.79.218/` и `CHANNEL_ID=@wifisonar`, затем ограничьте доступ: `chmod 600 /etc/t-bot-sonar.env`.
3. Создайте системного пользователя `tbot`, скопируйте `t-bot-sonar.service` в `/etc/systemd/system/` и выполните `systemctl daemon-reload`, `systemctl enable --now t-bot-sonar`.
4. Проверьте журнал: `journalctl -u t-bot-sonar -f`, затем отправьте боту `/start`.

Для обновления кода: `git pull` в папке проекта и `systemctl restart t-bot-sonar`. Не коммитьте секретный файл и не публикуйте токен.

Тексты вовлечения меняются в списке `HOOKS` в `bot.py`. Расписание меняется в `SCHEDULE` в `bot.py`. Для аналитики можно добавить UTM-параметры к `SITE_URL`.
